# Product Requirements Document (PRD)

**Project Name:** Synapse Notes  
**Version:** 1.0 (MVP)  
**Target Audience:** AI/ML Students, Researchers, and Technical Note-Takers  
**Deployment Target:** Vercel / Netlify (PWA - Web & Tablet Native Feel)  
**AI Bridge:** Model Context Protocol (MCP) Server for Codex, Claude Code, and Antigravity  

---

## 1. Executive Summary & Vision

**Synapse Notes** is an AI-native digital notebook tailored for college students and researchers using stylus-enabled tablets (such as the Samsung Galaxy Tab with S-Pen). 

Unlike traditional note-taking apps that trap handwriting inside closed formats or flat images, Synapse Notes preserves handwriting as editable, searchable data blocks. It exposes your notes to external AI coding and reasoning agents (Claude Code, Codex, Antigravity) via an open **MCP (Model Context Protocol)** bridge.

Students can scribble lecture notes, annotate professor's PDF slides, draw math diagrams, and have their AI agents read those notes, solve doubts, generate step-by-step explanations, and write interactive study cards directly into their notebook pages.

---

## 2. Problem Statement & User Personas

### The Problem
1. **Disconnected AI Tools**: Students take handwritten notes on tablets but have to manually re-type or screenshot concepts into ChatGPT or Claude when they don't understand a topic.
2. **Math & Diagram Friction**: AI/ML lectures are heavy with math formulas (loss functions, matrix multiplications) and neural network diagrams that are tedious to type in text-only note apps.
3. **Siloed Notes**: Existing apps (GoodNotes, Samsung Notes, Notability) do not have open interfaces that allow AI agents to read, query, or append notes automatically.

### User Persona: "Aarav" (AI/ML Engineering Student)
- **Device**: Samsung Galaxy Tab S9 + S-Pen + Laptop.
- **Workflow**:
  - Attends 3-4 hours of machine learning lectures daily.
  - Downloads professor's slide decks (PDFs) and writes handwritten annotations during class.
  - Gets stuck on complex math derivations (e.g., Backpropagation, Attention mechanisms).
  - Uses AI agents on his laptop (Claude Code / Codex / Antigravity) to research and code ML models.
- **Needs**: An app where his handwritten notes and slide annotations are instantly accessible to his laptop's AI agents without manual copy-pasting.

## 3. Core Features & Scope for Version 1.0

### 3.1. Tablet S-Pen Canvas Engine
- **Smooth Digital Ink**: Low-latency drawing with variable pressure sensitivity and tilt support for S-Pen.
- **Tool Palette**:
  - **Ballpoint Pen**: Crisp ink for handwriting.
  - **Highlighter**: Semi-transparent, layered underneath black text for readability.
  - **Stroke Eraser**: Tap or swipe to remove entire ink strokes quickly.
  - **Smart Shapes / Arrows**: Draw rough circles, boxes, or arrows with auto-straighten / snap support.
  - **Lasso Select**: Move, resize, or delete written sections.
- **Palm Rejection**: Rejects hand rest while writing with stylus.

### 3.2. PDF Lecture Slides & Document Markup
- **PDF Import**: Upload slide decks and research papers into any notebook.
- **Side-by-Side or Overlay Mode**: Write directly on top of slides or create a split-screen canvas beside the slide.
- **Exporting**: One-click export of the annotated PDF with vector handwriting embedded.

### 3.3. Lego-Block Note Structure
- Every page is stored as structured, composable blocks:
  - **Ink Block**: Raw vector strokes (JSON).
  - **PDF Block**: Embedded slide pages.
  - **Text / Markdown Block**: Typed text notes.
  - **Math Block**: Rendered LaTeX formulas ($W \cdot x + b$).
  - **AI Study Block**: Cards generated by AI agents.

### 3.4. The AI Bridge (Model Context Protocol - MCP)
- A dedicated **MCP Server** that exposes standard tools to Codex, Claude Code, and Antigravity:
  - `list_notebooks()`: Returns user's subjects, folders, and notebook titles.
  - `get_page_content(notebook_id, page)`: Returns slide text, transcribed handwriting, and drawings.
  - `search_notes(query)`: Full-text semantic search across all lectures and math formulas.
  - `insert_ai_study_card(notebook_id, page, title, content, diagram_type)`: Inserts a formatted study card, explanation, or diagram directly onto the student's notebook page.

### 3.5. Real-Time Tablet Sync
- Live updates between cloud backend and tablet interface.
- When an AI agent generates a study card or explanation on your laptop, it pops up immediately on the tablet canvas.

## 4. Non-Functional Requirements

- **Performance**: Canvas render loop at 60–120 FPS on Samsung Tab screens.
- **Responsiveness**: Fluid UI adapting from tablet portrait/landscape to laptop desktop views.
- **Reliability**: Auto-save after every stroke to prevent lost lecture notes.
- **Security**: Private API key authentication for MCP server and AI agent endpoints.
- **PWA Capabilities**: Installable on Samsung Tab home screen, offline viewing with service worker caching.

---

## 5. Success Metrics for Version 1.0

1. **Pen Latency**: Zero noticeable lag during rapid handwriting on Samsung Tab browser/PWA.
2. **AI Round-Trip**: External AI agent (Claude Code / Codex) can fetch notes and write a study card back in $< 3$ seconds.
3. **Export Quality**: Exported annotated PDFs maintain crisp vector resolution.
